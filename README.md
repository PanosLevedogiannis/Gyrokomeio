# Γυροκομείο Grill

Το site του Γυροκομείου, ψητοπωλείο στο Ναύπλιο από το 2011.
Ελληνικά και αγγλικά, για κινητό και υπολογιστή.

Απλό HTML, CSS και JavaScript. Χωρίς framework, χωρίς build: αλλάζεις ένα αρχείο, κάνεις refresh, τέλος.

## Τι αλλάζω πού

| Θέλω να αλλάξω… | Αρχείο |
|---|---|
| Τηλέφωνα, email, ωράριο, links Wolt / efood / Facebook, πιάτα ημέρας, κριτικές | `js/config.js` |
| Το μενού | `js/menu.js` |
| Ελληνικά κείμενα της σελίδας | `index.html` |
| Αγγλικά κείμενα | `js/i18n.js` |
| Φωτογραφίες | φάκελος `images/`, δες το [images/README.md](images/README.md) |
| Χρώματα, γραμματοσειρές, διάταξη | `css/style.css` |
| Το παιχνίδι «Γέμισε την πίτα» (χρόνος, ζωές, πόντοι) | `js/game.js` (στην αρχή του αρχείου) |

Οι φωτογραφίες μπαίνουν μόνες τους: ρίχνεις το αρχείο στο `images/` με το σωστό όνομα και εμφανίζεται.

**Μετά από αλλαγή σε αρχείο `css/` ή `js/`:** άλλαξε τον αριθμό `?v=...` στο τέλος των συνδέσμων στο `index.html` (και στο `404.html`), π.χ. `?v=20260924b` → `?v=20261001`. Έτσι οι browser παίρνουν αμέσως τη νέα εκδοχή αντί για παλιό αντίγραφο. Για να το δεις εσύ αμέσως: Cmd+Shift+R.

## Δοκιμή στον υπολογιστή

```bash
python3 -m http.server 8000
```

και άνοιξε http://localhost:8000 . Για τα αγγλικά: http://localhost:8000/?lang=en

## Πριν βγει κανονικά στον αέρα

- [ ] Σβήσε τη γραμμή `<meta name="robots" content="noindex">` στο `index.html` (τώρα κρύβει το preview από τη Google)
- [ ] `showPlaceholders: false` στο `js/config.js` (κρύβει τα κουτάκια «Θέση για…»)
- [ ] Φωτογραφίες στο `images/` (λίστα λήψεων: [images/README.md](images/README.md))
- [ ] 3 έως 6 πραγματικές κριτικές από το Google στο `js/config.js`, αυτούσιες
- [ ] Ένα δοκιμαστικό μήνυμα από τη φόρμα και κλικ στο email ενεργοποίησης του FormSubmit
- [ ] Επιβεβαίωση με το μαγαζί: email, ωράριο, κινητό, ποια πιάτα είναι χορτοφαγικά, τύποι πίτας, αν τους αρέσει το λογοπαίγνιο στην «Ιστορία»
- [ ] Όταν αποφασιστεί το τελικό domain: `og:image` στο `index.html` με το νέο απόλυτο URL
- [ ] Μεταφορά του gyrokomeio.gr (CNAME + DNS) μόνο όταν το αποφασίσει ο ιδιοκτήτης

## Απόρρητο

Κανένα cookie παρακολούθησης, κανένα analytics. Οι γραμματοσειρές είναι στο site (όχι από Google Fonts).
Ο χάρτης της Google φορτώνει μόνο όταν ο επισκέπτης πατήσει «Εμφάνιση χάρτη».
Η φόρμα στέλνει μέσω [FormSubmit](https://formsubmit.co).
